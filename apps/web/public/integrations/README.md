# Логотипы сервисов, с которыми есть интеграция

Файлы лежат у нас, а не загружаются с чужих сайтов: страница не должна зависеть
от того, работает ли сейчас сайт партнёра, и не должна сообщать ему, кто открыл
нашу витрину.

Логотипы используются, чтобы **назвать сервис, с которым у платформы есть
интеграция**, — это и есть тот случай, для которого компании выкладывают свои
знаки. Мы их не перерисовываем и не переделываем (единственное исключение
отмечено ниже), не ставим рядом со своим знаком так, будто это совместный
продукт, и не утверждаем, что кто-то из них нас одобрил. Права на сами знаки
остаются у их владельцев.

## Откуда каждый файл

С **Викисклада**, где у файла указана лицензия машиночитаемо — все пять помечены
как общественное достояние (знак слишком прост, чтобы быть объектом авторского
права; товарный знак при этом у владельца):

| Файл | Страница на Викискладе | Лицензия |
|---|---|---|
| `yookassa.svg` | `File:ЮKassa logo.svg` | Public domain |
| `bitrix24.svg` | `File:Bitrix24-logo-ru.svg` | Public domain |
| `1c.svg` | `File:1C Company logo.svg` | Public domain |
| `cdek.svg` | `File:CDEK logo.svg` | Public domain |
| `metrica.svg` | `File:Yandex Metrica icon.svg` | Public domain |

С **сайтов самих компаний** — это их действующие знаки в том виде, в каком они
их публикуют. Отдельной свободной лицензии у этих файлов нет, они используются
как название партнёра:

| Файл | Источник |
|---|---|
| `amocrm.svg` | `amocrm.ru/static/assets/svg/amo.svg` |
| `moysklad.svg` | `moysklad.ru/favicon.svg` |
| `iiko.svg` | `iiko.ru/wp-content/uploads/2026/05/iiko-1.svg` |
| `rkeeper.svg` | `rkeeper.ru/local/templates/template.rkeeper/img/logo.svg` |
| `yclients.svg` | знак из шапки `yclients.ru` (сайт закрыт от прямой загрузки) |

## Что изменено

`amocrm.svg` — на сайте знак **белый**, он нарисован для тёмной шапки и на нашей
белой карточке не виден вообще. Форма не тронута, изменён только цвет заливки на
тёмный: это штатная одноцветная инверсия. Больше ни один файл не менялся, кроме
чисто технической уборки — убраны комментарии и метаданные редактора, у двух
файлов дописан `viewBox`, без которого они не масштабируются.

## Если логотип устареет

Компания меняет знак — заменить файл здесь, ничего больше трогать не нужно:
`Capabilities.tsx` ссылается на имя файла, а не на его содержимое.
