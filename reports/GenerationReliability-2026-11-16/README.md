При объединении веток нельзя использовать точное значение одной ветки как общий факт. Шаблонный контроль не создаёт свидетельств подключения SDK. Для неподдерживаемого условия диагностика включает файл, строку, столбец и подсказку. Локальная фикстура повторяет синтаксис из снимка, включая `.trim()` и цепочку `&&` → тернарное выражение → `||`. Отдельные проверки покрывают ранний возврат, JSX через переменную или функцию, видимость, мутации и небезопасное приведение в шаблоне. Штатный checkout проверен отдельно.
