# Регистратор живого QA

Перенос проверенного локального регистратора без изменений поведения. Нет внешних npm-зависимостей. Проверка: `node --test qa-tools/live-recorder/recorder.test.mjs` из корня проекта.

Полная инструкция и 67 ID: [HANDOFF.md](../../docs/qa/2026-10-02-handoff/HANDOFF.md), [scenarios.json](../../docs/qa/2026-10-02-handoff/scenarios.json).

Модуль импортируется в уже разрешённый cua_repl; управляет только переданной вкладкой. `createRecorder({publicDir, privateDir, secrets, catalog})`, `scenario(id)`, `instrumentTab(tab)`, `run(action, fn, tab)`, `checkpoint(tab)`, `finish(status, evidence)`.

Обёртка пишет before/after для locator click/fill/check/press/select и навигации, автоматически сохраняет DOM, warn/error, снимок, hash и состояние в JSON/JSONL. Чтения и неохваченные методы сами не создают записи. `checkpoint` принимает ровно одну вкладку. Ошибки действия и сбора остаются в журнале и не считаются успешными.

Один экземпляр на public-папку. На каждом компьютере отдельная папка прогона вне checkout. Исходные DOM/снимки остаются private; приватную папку защитить правами ОС. Public-текст очищается по шаблонам и переданным приватным значениям. Скриншоты автоматически не обезличиваются. Перед отправкой проверить текст и изображение вручную. Не добавлять журналы, cookie или список secrets в Git.

PASS не выставляется автоматически. Каталог задаёт ID/expected; новые статусы НЕ импортируют ранее унаследованные PASS. Модуль не перехватывает сетевой трафик, HTTP-тела, cookie и серверные логи.
