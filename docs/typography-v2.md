# Типографика генерируемых приложений

По умолчанию генератор выбирает из 20 закреплённых семейств и 24 сочетаний,
включая 6 троек. Приоритет: явно выбранный пользователем шрифт, затем стиль
из запроса или выбранного preset, затем тематика. Третий шрифт получает
конкретную роль: интерфейс, код или короткий акцент. Он не заменяет основной
текст. Обычная правка следует сохранённым `typography.json` и `DESIGN.md`.

В чате доступна кнопка «Шрифт»: название бесплатного семейства, ссылка на его
страницу Google Fonts/Fontsource или файл TTF/OTF/WOFF/WOFF2. Файлы можно
перетащить или вставить вместе с изображениями. Можно назначить роли
заголовков, текста, интерфейса, акцентов и кода. Также понимается явная команда
в чате, например `Используй шрифт Montserrat для заголовков`.

Набор по умолчанию не ограничивает владельца. Имена разрешаются через
проверенный бесплатный каталог Fontsource с фиксацией версии, SHA512 пакета,
лицензии и фактических WOFF2. Произвольный URL сервер не скачивает; для других
источников используется загрузка файла. Пакеты рассматриваются только как
данные: их scripts/hooks не выполняются. Если семейство недоступно, запрос
получает явную ошибку с возможностью загрузить файл вместо тихой подмены.

Загрузка ограничена 8 MiB исходного файла, 1 MiB нормализованного face, 6
выборами в одном сообщении; действуют отдельная пользовательская квота и
общая квота приватного хранилища. OTS и FontTools работают в отдельном
процессе без окружения приложения, с ограничениями времени/CPU/RAM/output.
Сервер проверяет владельца, проект и digest. Принятые шрифты не истекают вместе
с черновиками. Смена файла или роли под прежним idempotency key отклоняется.

Пользовательские WOFF2 материализуются в отдельных UTF-8 CSS с data URLs:
обычный source repository сохраняет текст, поэтому простая запись бинарного
файла в `public/fonts` недостаточна. CSS, manifest и license входят в snapshot.
Bootstrap имеет собственный идемпотентный `font_apply` с теми же fenced-write
receipts, что и starter; cold resume использует принятые pins без нового поиска.

Проверки реализации: `test_semantic_typography.py`, `test_owner_fonts.py`,
`test_font_assets_api.py`, `test_owner_font_bootstrap.py`,
`test_owner_font_migration.py` и web `prompt-font-attachments.test.tsx`.
Linux release gate устанавливает OTS и выполняет реальные PG/OTS проверки.
Заморозка зависимостей и реальная Next-сборка проверены для всех 230 core faces.
Prata не содержит ₽: цены и числовые роли используют читаемое основное семейство.
