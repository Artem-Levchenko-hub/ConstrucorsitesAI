# Аккаунт без реквизитов: отказ от лишних данных (23.09.2026)

Решение владельца (бриф от 22.09, «полностью делаем отказ от доп данных»): аккаунт Yleum — это
email и пароль. ИНН, ОГРН, ФИО, должности, телефоны и адреса платформа не спрашивает и не хранит;
бизнес за ботом проверяет сам MAX при верификации профиля. Пользователь передаёт Yleum только
токен бота, получает ссылку приложения и вставляет её в MAX. Посетители опубликованных
приложений по умолчанию не сохраняются; если приложение различает посетителей — хранится только
`max_user_id`. Реквизиты компании нужны только для счёта или когда Yleum сам формирует
юридические страницы приложения (и тогда — только название владельца и контактный email).
