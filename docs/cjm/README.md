# Интерактивный CJM Omnia MAX

Каноническая интерактивная версия:

- [`omnia-max-cjm-customer-flow.html`](./omnia-max-cjm-customer-flow.html)

Файл автономный: стили, экраны и сценарии встроены внутрь. Его можно открыть напрямую в браузере без установки зависимостей и запуска проекта.

В CJM показаны:

- 23 уникальных экрана владельца и путь повторного входа;
- 5 экранов конечного клиента;
- 9 этапов полного пути;
- 5 быстрых маршрутов;
- 9 важных развилок и ошибок с понятным восстановлением;
- 28 экранных вопросов юристу: кнопка `§` показывает риск для ООО «Кортэл» и нужный результат проверки;
- Free, Pro и Business, оплата через ЮKassa, версии, подготовка бота в MAX Partner, безопасный вход, публикация и подключение готового URL.

Внутренняя кухня, серверные команды и технические логи намеренно скрыты: это пользовательский путь, а не схема реализации.

## Проверенная последовательность MAX

- Для Free-теста достаточно обычной ссылки: бот и токен не требуются.
- Для приложения с подтверждённым профилем пользователя сначала создаётся и проходит модерацию бот в MAX Partner.
- Только после модерации появляется токен; Omnia принимает его один раз и не показывает повторно.
- После публикации production URL добавляется в расширенные настройки бота и проверяется кнопка запуска.

Основание: официальные разделы MAX о [создании и управлении ботом](https://dev.max.ru/docs/chatbots/bots-create/manage), [валидации данных запуска](https://dev.max.ru/docs/webapps/validation) и [управлении URL мини-приложения](https://dev.max.ru/docs/webapps/introduction).
