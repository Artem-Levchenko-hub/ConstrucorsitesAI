# Превью без MAX: проверка основы, 15 октября 2026

## Что меняется

Владелец открывает приложение на постоянной странице Yleum
`/max/{project_id}/preview`. Эта страница остаётся родителем встроенного
приложения и может восстанавливать его короткую сессию без установки MAX.
Переход в отдельную вкладку больше не зависит от одноразовой ссылки.

Если защищённый шлюз обнаружил истёкшую сессию ещё до загрузки приложения,
он показывает собственную страницу восстановления. Код приложения и его
данные до подтверждения доступа не выдаются. Настоящий отклонённый вход MAX
не заменяется доступом владельца.

История сборок используется редактором и отдельной страницей через один
модуль. Каждая страница истории сохраняет идентификатор снимка, для которого
была запрошена: запоздавший ответ не разрешает показать другую сборку.

Проверка готовности повторно использует уже прочитанную квитанцию начальной
подготовки. На измеренном пути число чтений SQL уменьшилось с семи до шести.
Условия принятия и отклонения сборок сохранены; ускорение в миллисекундах
не измерялось.

## Что ещё не подтверждено

Эта поставка не создаёт гостевую ссылку. Гостям нужны отдельные среда,
учётные данные и демо-база, а также запрет оплат и внешних отправок на сервере.
Предоставлять гостю ссылку с полномочиями владельца нельзя.

Текущий адрес черновика изменяемый. Для гарантии показа последней принятой
версии при неудачной новой сборке ещё нужны отдельный неизменяемый артефакт
и изолированная база кандидата. Сохранённый URL сам по себе этого не даёт.

Полный серверный набор проверок требует Linux и отдельный PostgreSQL.
Локальная попытка на Windows остановилась на отсутствующих зависимостях
оркестратора и недоступной тестовой базе. Это не успешный полный прогон;
окончательный вердикт должен дать CI точной опубликованной ревизии.

Настоящая производственная сборка Next.js с отключёнными моками прошла
компиляцию, проверку типов и подготовку 46 страниц. Упаковка `standalone`
на Windows завершилась отказом `EPERM` при создании символической ссылки
на пакет React/Next. Это ограничение локального окружения; готовый релизный
образ этим запуском не получен. Производственную конфигурацию ради обхода
ошибки не меняли. Упаковку должен подтвердить Linux CI.

согласование обновления gateway в штатном запросе владельца с сохранением
базы, идентичности и блокировок активных операций. Простое отображение
каталога не подтверждает эту часть приёмки.

## Приёмка после выкладки

1. Войти владельцем, открыть постоянную страницу и отдельную вкладку без MAX.
2. Дождаться окончания сессии и выполнить одно действие: сессия должна
   восстановиться, действие не должно отправиться повторно.
3. Повторно открыть страницу; проверить исходные записи и владельцев.
4. Проверить отказ другому аккаунту и отклонённому запуску MAX.
5. Проверить прежнюю привязку бота amoCRM без её переноса.
6. Только после этой основы добавлять приёмку неизменяемой принятой версии
   и отдельных гостевых демо-сред.
