# Главная: карусель четырёх экранов

Последнее уточнение пользователя заменяет прежний вариант «Клиент / Персонал». В hero остаются только экраны миниприложений. Выбранный экран впереди, соседние позади слева/справа; нажатие на соседний выводит его вперёд с анимацией.

Порядок по кругу: кофейня → услуги → клуб → магазин. Начало: магазин слева, кофейня впереди, услуги справа. После выбора услуг: кофейня слева, услуги впереди, клуб справа.
