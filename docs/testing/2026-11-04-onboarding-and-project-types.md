# Дополнительные замечания: обучение, регистрация, типы приложения

Продолжает опубликованные пакеты `def7c873` и `5eb02290`. Последующие комментарии пользователя добавляются к исходной задаче генерации и каталога.

Принятые требования:

- Регистрация: звёздочки у четырёх обязательных полей и трёх обязательных согласий; рассылка остаётся необязательной. Удалить три пояснения под кнопкой.
- Подтверждение email: показывать введённый адрес, срок ссылки 24 часа и кода 10 минут; ясный текст без «Если письмо уже пришло». API сейчас не доказывает фактическую доставку, поэтому без неподтверждённого «Мы отправили». Повторная отправка подтверждает принятие запроса.
- Первый вход: центральное приветствие перед коротким обучением; далее линейные Next/Back без списка «Раздел обучения». Во время тура фон неактивен. Незавершённый тур возобновляется перед созданием; завершение само не создаёт проект. Прежний completed, повтор обучения, смена аккаунта и ошибки storage учитываются отдельно.
- Обучение: верхняя подпись «Обучение», первая фраза шага про идею без прежнего продолжения, ясная справка по созданию приложения и его запуску в MAX. Исправить перекрытие подсвеченного заголовка руководства.
- Карточки: «Готовые приложения», «Открой готовое приложение и поправь его под себя»; существующий мастер с готовой идеей сохраняется.
- Мастер: можно выбрать несколько типов. Все выбранные сценарии сохраняются при возврате, попадают в проверку и один запрос создания. Первичный тип совместим с прежним API; дополнительные сценарии передаются через существующие features, UI MaxFeature не расширяется произвольными строками. Каталог и его цены/ID сохраняются при другом первичном типе.
- Справка: фраза создания приложения с одной опечаткой в каждом из двух слов предлагает подходящий вопрос; автоматический ответ остаётся строгим, посторонние вопросы не получают ответ по старому контексту.
