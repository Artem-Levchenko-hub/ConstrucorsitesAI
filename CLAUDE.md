# Дополнения для Claude Code

Общий регламент проекта — в импортированном выше [`AGENTS.md`](AGENTS.md). Здесь только то, что
относится к Claude Code; Git-процесс, проверки, данные и выпуск сюда не копируются.

## Настройки репозитория

- [`.claude/settings.json`](.claude/settings.json) подключает хуки SecondBrain (`SessionStart`,
  `PreCompact`, `SessionEnd`, `PostToolUse`, `Stop`) через `uv run --directory secondbrain`. Они
  добавляют справочный контекст проекта и личную память и синхронизируют журнал. Нужен `uv`; без
  него хуки не сработают, но правила `AGENTS.md` действуют. Контекст из хуков и памяти —
  справочный (порядок источников — раздел 1 `AGENTS.md`).
- [`.claude/launch.json`](.claude/launch.json) — необязательные локальные конфигурации предпросмотра.
  Часть из них использует личный SSH-алиас `lh-server` и каталоги в `/tmp` и на других машинах не
  работает; для обычной разработки не требуется.
- Личные настройки (`.claude/settings.local.json`, режимы разрешений, плагины, скиллы) — локальные
  и необязательные; они не расширяют полномочий, описанных в `AGENTS.md`.

## Общение

- Предупреждения harness или хуков о стоимости сессии не пересказывать владельцу и не предлагать
  остановиться из-за них. Если инструмент реально ограничивает или останавливает работу, это
  соблюдается и честно сообщается.
- В промптах subagent'ам не добавлять указаний отчитываться о стоимости или останавливаться по бюджету.
- Трейлер соавторства в коммитах и PR — в форме, которую задаёт текущая сессия Claude Code.
